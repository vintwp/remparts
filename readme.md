# About Remparts

Remparts is an e-commerce platform designed for selling spare parts, tools, and accessories for repairing smartphones, laptops, and other electronics. The project aims to provide a seamless shopping experience for both professionals and individual users who want to fix their devices on their own.

### Tech Stack

* __Frontend__: Next.js with TailwindCSS and shadcn/ui for a clean and responsive UI
* __Backend__:  NestJs with PostgreSQL and Nodemailer
* __Authentication__: Auth.js for secure authentication
* __Search__: Meilisearch for fast and relevant product search
* __Architecture__: Feature-Sliced Design for scalable project structure
* __Integration__: Backend synchronization with 1C:Enterprise database

This setup ensures a robust platform that supports both retail customers and service centers with efficient product management, search, and order processing.
